# FairHireAI — PROTOCOL V2 | START HERE (Mac + VS Code)

This is the complete executable source with the **original Kaggle `recruitment_data.csv` (1,500 rows)**. It supports real paid OpenAI Responses API requests and *separate* local/mock software tests. You do not need `pip install` for this version: all the runnable code uses Python 3.10+ standard-library modules.

## Why this is V2

Your first successful live pilot (V1, November 16, 2026) had **8 API response IDs but only 6 valid parsed evaluations**. Two responses for pair `P00961` returned scores `76` and `81` with `Interview`, which violated the application’s existing threshold rule. The prompts had not explicitly stated the rules they were being checked against. V2 corrects this **specification mismatch** by including the formula and recommendation thresholds in **both** prompt strategies. Model outputs remain unmodified. V2 also exports `scoring_audit.csv` to identify mathematical deviations from the predefined rubric. **V1 and V2 must never be pooled as if they were generated by the same prompt protocol.**

**Do not copy old results into the new project.** Preserve the old `FairHireAI_REAL_OPENAI_COMPLETE` folder and its `results_live_openai_...` files unchanged for your methodology discussion. New results will be recorded in a new folder and labeled with V2 protocol metadata. This package contains no fabricated real LLM results.

## 10. Scientific interpretation

This is **research-only recruitment support auditing**, not a real hiring system. Because a fixed arithmetic rubric is specified, an unvarying output may reflect compliance with that rule rather than broad fairness. Differences may reflect arithmetic failure, prompt sensitivity, randomness or demographic-cue sensitivity. Report all outcomes and don't describe either result as proof of general fairness or discrimination. V1 findings can be discussed as an earlier pilot that motivated transparent pre-experiment protocol clarification.
